Reliability
===========

.. requirement:: VMCREL00001
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall provide redundant vehicle management systems for high
   availability and reliability.

.. requirement:: VMCREL00002
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall support automatic switchover to the redundant system
   in case of a failure in the primary system.

.. requirement:: VMCREL00003
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall provide real-time monitoring of system health and
   availability.

.. requirement:: VMCREL00004
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall provide detailed information about the cause and
   effect of switchovers.

.. requirement:: VMCREL00005
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall ensure data consistency and integrity between the
   primary and redundant systems.

.. requirement:: VMCREL00006
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall support integration with maintenance and
   troubleshooting systems for efficient resolution of faults.

.. requirement:: VMCREL00007
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall comply with relevant redundancy standards, such as
   RTCA DO-254.

.. requirement:: VMCREL00008
   :satisfies: SEG-AIR-008
   :subsystem: REL
   :verification: Test
   :last-modified-by: doors-import

   The software shall provide the ability to perform redundancy system
   tests.
