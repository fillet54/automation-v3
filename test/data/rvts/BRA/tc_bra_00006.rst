==========================
Blocked Without Hydraulics
==========================
Needs the hydraulics pressurised, which nothing in the example set
does.

.. warning::

   Blocked on purpose: the precondition has no heal, so probes release
   the job and force mode ends it blocked. VMCBRA00005 rolls up Partial.

Requirements
------------
1. :req:`VMCBRA00005`

.. rvt::

   (Precondition "Hydraulics pressurised"
     (reading-is? :hydraulics :on))

Steps
-----

.. rvt::

   (brake-pressure-ok? 10)
