============================
Braking In Every Environment
============================
Runs in both the simulator and the bench, one run each.

Requirements
------------
1. :req:`VMCBRA00004`
2. :req:`VMCBRA00008`

.. rvt::

   (environments :sim :bench)

   (Precondition "Demo running in normal mode"
     (demo-in-mode? :normal)
     :heal (start-demo :normal))

Steps
-----

.. rvt::

   (quietly (Wait 1))
   (if (try-ok? (Verify (.version demo) = "1.1.0"))
     (Wait 2)
     (Wait 1))
   (Verify (brake-pressure-ok? 40))
