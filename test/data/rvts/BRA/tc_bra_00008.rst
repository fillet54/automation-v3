=================================
Hard Stop From A Configured Start
=================================
Starts the demo UUT from a configuration with the StartDemo block, which
shows its configuration as a table, then checks the brakes hold. Its
values come from the script's definitions section.

Requirements
------------
1. :req:`VMCBRA00001`

.. rvt::
   :definitions:

   (def stop-pressure 70)
   (def stop-temperature 300)

.. rvt::

   (Precondition "Demo configured for a hard stop"
     (reading-is? :brake-pressure stop-pressure)
     :heal (StartDemo {:mode :emergency
                       :readings {:brake-pressure stop-pressure
                                  :brake-temperature stop-temperature}}))

Steps
-----

.. rvt::

   (demo-in-mode? :emergency)
   (brake-pressure-ok? (reading :brake-pressure))
