=========================
Brake Pressure Monitoring
=========================
Monitors brake pressure and checks it against the brake limit
(80, from BRA/core.rst overriding the root's 100).

Requirements
------------
1. :req:`VMCBRA00001`
2. :req:`VMCBRA00005`

.. rvt::

   (Precondition "Demo running in normal mode"
     (demo-in-mode? :normal)
     :heal (start-demo :normal))

Steps
-----

.. rvt::

   (set-reading :brake-pressure 60)
   (Verify (reading :brake-pressure) <= max-pressure)
