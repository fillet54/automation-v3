====================
Brake Pressure Modes
====================
Checks the brake pressure limit holds in each braking mode. The
precondition starts the demo UUT with the variation's mode and pressure,
so runs of the same mode can reuse a warm UUT.

Requirements
------------
1. :req:`VMCBRA00002`
2. :req:`VMCBRA00003`

Each mode keeps its own headroom below the limit. Limp-home runs closer
to it, so its block below replaces the default for that variation only.

.. rvt::
   :definitions:

   (def headroom 15)

.. rvt::
   :definitions:
   :variations: limp-home

   (def headroom 5)

.. rvt::

   (variations "mode pressure"
     ["normal"    [:normal 60]
      "limp-home" [:limp-home 75]
      "emergency" [:emergency max-pressure]])

   (Precondition "Demo running in the variation's mode"
     (in-variation-mode?)
     :heal (StartDemo {:mode mode
                       :readings {:brake-pressure pressure}}))

Steps
-----

.. rvt::

   (set-reading :brake-pressure pressure)
   (brake-pressure-ok? (reading :brake-pressure))

Emergency braking
-----------------
In emergency mode the pressure runs right at the limit, and must stay
there.

.. rvt::
   :variations: emergency

   (Verify (reading :brake-pressure) = max-pressure)

Normal and limp-home braking keep their headroom below the limit.

.. rvt::
   :variations: normal, limp-home

   (Verify (reading :brake-pressure) <= (- max-pressure headroom))
