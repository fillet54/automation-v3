==========
Fuel Types
==========
Loads each supported fuel type.

Requirements
------------
1. :req:`VMCFUE00002`
2. :req:`VMCFUE00003`

.. rvt::

   (variations "fuel-type litres"
     ["jet-a"  [:jet-a 45]
      "avgas"  [:avgas 30]])

   (Precondition "Demo running in normal mode"
     (demo-in-mode? :normal)
     :heal (start-demo :normal))

Steps
-----

.. rvt::

   (set-reading :fuel-type fuel-type)
   (set-reading :fuel-level litres)
   (Verify (fuel-level-ok? (reading :fuel-level)))
