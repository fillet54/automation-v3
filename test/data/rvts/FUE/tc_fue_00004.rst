===========================
Fuel Uses Brake Definitions
===========================
Uses its own folder's fuel definitions and imports the brake folder's
pressure check. The import only adds definitions: BRA's limit of 80 does
not override the root's 100 for this script.

Requirements
------------
1. :req:`VMCFUE00006`
2. :req:`VMCFUE00008`

.. rvt::

   (import BRA)

   (Precondition "Demo running in normal mode"
     (demo-in-mode? :normal)
     :heal (start-demo :normal))

Steps
-----

.. rvt::

   (fuel-level-ok? 40)
   (brake-pressure-ok? 90)
